Python / LangGraph / Gemini / RAG

Bank Churn Analyst Agent

An LLM agent that answers business questions about the same 10,127 customers. It decides which tools to use: it writes and runs read-only SQL, searches the project docs (Chroma RAG), and stops for human approval before exporting a call list. Every answer shows the SQL behind it.

Result: 26 of 27 evaluation questions passed (96%), scored automatically against an answer key checked in pytest. The one miss reported two groups separately instead of combined. When the main model ran out of free quota, fallback models kept every question answered.

Power BI / DAX / Power Query

Credit Card Customer Churn

A three-page Power BI report on 10,127 bank credit card customers: an overview, the behavioural drivers of churn, and a retention watchlist built from a transparent six-rule risk score.

Result: demographics barely move churn (13 to 17% across income bands), but customers with under 60 transactions a year churn at about 35%. The score flags 74% of past churners and 1,137 active high-risk customers. It was built and tested on the same snapshot, so it needs validating on new data.

Tableau / Python / pandas

Mobile Money Fraud Risk Analysis

An interactive dashboard on the synthetic PaySim dataset showing where fraud concentrates by transaction type, amount, and time. A pandas script keeps all 8,213 fraud cases and samples 200,000 legitimate rows.

Result: fraud appears only in TRANSFER (19.60%) and CASH_OUT (5.53%) in the sample. Sampling inflates these rates compared with the full dataset.

Python / PyTorch / time series

IMU Distance Estimation for a Mobile Robot

Estimates how far a Direct Drive Diablo robot drove from a phone's accelerometer and gyroscope. Compares double integration, a constant-speed baseline, Random Forest, SVR, and a CNN-GRU using run-grouped cross-validation.

Result: about 0.35 m error (7%) on held-out 5 m runs versus 3.03 m for double integration. On an unseen 27 m recording the learned models underestimated by 10 to 14%.
